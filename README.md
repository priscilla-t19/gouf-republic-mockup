# GOUF Republic — Streetwear Website

I built this website for **GOUF Republic**, a locally owned Botswana streetwear brand founded by my friend **Rethabile, popularly known as GoufDon**.

Beyond being a developer, I'm also the **First Lady of GOUF** and model for the brand, so this project was a fun way to combine my involvement in fashion with my passion for technology.

I took on this project as an opportunity to **put my frontend development skills to the test**, experimenting with responsive design, creative layouts, and interactive components while bringing GOUF's artistic identity to life digitally.

Built using **React, TypeScript, and CSS**, this is a personal frontend concept rather than the brand's official website.

A little fashion, a little code, and a lot of creativity.
